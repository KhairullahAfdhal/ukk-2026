## PEMINJAMAN BUKU SEKOLAH

Aplikasi pengelolaan perpustakaan digital yang dikembangkan menggunakan PHP Native 
dengan pendekatan OOP (Object Oriented Programming) serta pola desain MVC (Model View Controller).

Sistem ini dirancang untuk memudahkan manajemen katalog buku, pendataan anggota, pencatatan transaksi peminjaman serta pengembalian, 
dan penyediaan laporan rekapitulasi yang terintegrasi dengan hak akses pengguna.

---

## FITUR UTAMA

### Admin
- Mengelola data pengguna (siswa/anggota)
- Mengelola data kategori
- Mengelola data inventaris buku (Tambah, Edit, Hapus)
- Memverifikasi dan memantau transaksi peminjaman & pengembalian
- Mengelola denda keterlambatan pengembalian buku
- Mengelola dan mencetak laporan perpustakaan

### Anggota / Siswa
- Melakukan pencarian di dalam riwayat peminjam
- Mengajukan permintaan peminjaman buku secara online
- Melihat riwayat status peminjaman dan pengembalian pribadi
- Memeriksa denda atau tenggat waktu pengembalian buku

## Konsep MVC

### Model
Berfungsi untuk mengelola data, memproses logika bisnis, dan berinteraksi langsung dengan database perpustakaan.

### View
Berfungsi menampilkan antarmuka (UI) halaman web kepada pengguna (admin, pustakawan, maupun anggota).

### Controller
Berfungsi sebagai pengatur alur program yang menghubungkan antara Model dan View.
